E-Commerce Portal

A simple front-end E-Commerce Portal developed using HTML, CSS, and JavaScript. This project demonstrates core e-commerce functionalities with client-side validation and dynamic content rendering using DOM manipulation.

Features

- User Registration & Login
- Product Listing
- Wishlist Management
- Order History
- Customer Reviews
- Product & Order Issue Reporting
- Contact & About Sections
- Local Storage for User Data

Technologies Used

- HTML5
- CSS3
- JavaScript (DOM & Local Storage)

Project Structure

E-Commerce-Portal/
├── index.html
├── app.css
├── app.js
└── README.md

How to Run

1. Download or clone the repository.
2. Open "index.html" in any web browser.
